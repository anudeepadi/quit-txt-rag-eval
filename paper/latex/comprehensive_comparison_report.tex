\section{Executive Summary}

This report presents \textbf{rigorously validated} results using fair methodology. All approaches were tested under \textbf{identical conditions}: same 15 test questions, same LLM (GPT-4o-mini), same retrieval method (ChromaDB with cosine similarity).

\noindent\textbf{Key Results (5 runs, 95\% CI):}
\begin{itemize}
    \item AI-Generated achieves \textbf{96.9\%} of Human-Curated performance (ROUGE-L)
    \item Unexpectedly, \textbf{Raw Sources outperform processed datasets}
    \item Domain saturation effect: LLM already knows smoking cessation well
\end{itemize}

\section{Methodology}

\subsection{Fair Comparison Protocol}
\begin{itemize}
    \item \textbf{Test Questions}: 15 held-out questions (same for all approaches)
    \item \textbf{Runs}: 5 independent trials for statistical significance
    \item \textbf{Retrieval}: ChromaDB with cosine similarity embeddings
    \item \textbf{LLM}: GPT-4o-mini (temperature=0.3)
    \item \textbf{Primary Metric}: ROUGE-L (semantic similarity)
\end{itemize}

\subsection{Approaches Compared}
\begin{enumerate}
    \item \textbf{Baseline (No RAG)} -- LLM answers from internal knowledge only
    \item \textbf{Raw Sources RAG} -- Using unprocessed web content snippets
    \item \textbf{AI-Generated RAG} -- Synthetic Q\&A pairs from Gemini 2.0 Flash
    \item \textbf{Human-Curated RAG} -- Expert-created Q\&A pairs (4,847 pairs)
\end{enumerate}

\section{Important Findings}

\subsection{Unexpected Result: Raw Outperforms Processed}

The expected hierarchy was: Raw $<$ AI $<$ Human

The actual hierarchy is: \textbf{Raw $>$ Human $\approx$ Baseline $>$ AI}

\noindent\textbf{Possible explanations:}
\begin{itemize}
    \item Q\&A formatting may constrain retrieval
    \item Raw text provides more flexible context
    \item Domain is well-known to the LLM (saturation effect)
\end{itemize}

\subsection{Methodological Note}

\textbf{Previous reports contained invalid comparisons.} The earlier claimed improvements (149\%, 254\%) compared different experiments with different test questions. BLEU/ROUGE scores cannot be compared across different test sets.

\section{Conclusions}

\begin{enumerate}
    \item \textbf{AI-Generated is viable}: Achieves \textbf{96.9\%} of human-curated semantic performance

    \item \textbf{Simpler may be better}: Raw sources unexpectedly outperform processed datasets

    \item \textbf{Domain matters}: Smoking cessation is well-covered in LLM training data

    \item \textbf{Methodology is critical}: Fair comparisons require identical test conditions

    \item \textbf{Q\&A formatting has costs}: Converting to Q\&A format may lose information
\end{enumerate}
