# QuitTxt RAG Evaluation — Data Dictionary

## Overview

This project evaluates whether Retrieval-Augmented Generation (RAG) improves a GPT-4o-mini smoking cessation counselor, and whether an AI-generated knowledge base can match a human-curated one. The project name "QuitTxt" refers to the SMS-based smoking cessation intervention that the original dataset was built for.

---

## Datasets

### 1. Human-Curated QA Dataset

| Property | Value |
|---|---|
| **Original file** | `qa.jsonl` (root, legacy location) |
| **Canonical file** | `data/human_curated_qa.jsonl` |
| **Format** | JSONL — one JSON object per line |
| **Records** | 4,431 question-answer pairs |
| **Origin** | Manually curated by domain experts for the QuitTxt SMS cessation program |
| **Date** | Pre-October 2025 |
| **Schema** | `{"id": "id00001", "question": "...", "answer": "..."}` |
| **Used by** | `scripts/ragas_evaluation.py` (as `human_rag`), `scripts/fair_rag_evaluation.py` |

The human-curated dataset is the gold-standard knowledge base. Each QA pair was written or reviewed by smoking cessation counselors. This dataset is used to build a ChromaDB vector store for retrieval during the `human_rag` experimental condition.

---

### 2. AI-Generated QA Dataset

| Property | Value |
|---|---|
| **JSON file** | `data/ai_generated/ai_generated_qa_full.json` |
| **JSONL file** | `data/ai_generated/ai_generated_qa.jsonl` |
| **Format** | JSON (wrapped with metadata) and JSONL (flat, one pair per line) |
| **Records** | 5,936 question-answer pairs |
| **Origin** | Generated by Gemini 2.0 Flash with faithfulness safeguards |
| **Date** | December 11, 2025 |
| **Schema (JSON)** | `{"metadata": {...}, "qa_pairs": [{"question": "...", "answer": "..."}]}` |
| **Schema (JSONL)** | `{"id": "ai_00000", "question": "...", "answer": "..."}` |
| **Used by** | `scripts/ragas_evaluation.py` (as `ai_rag`), `scripts/fair_rag_evaluation.py` |

The AI-generated dataset was created as an automated alternative to the human-curated dataset. The core research question is whether this cheaper, faster-to-produce dataset can match the human one in RAG quality. The JSONL version was derived from the JSON file for consistency with other datasets.

---

### 3. Web-Scraped QA Dataset

| Property | Value |
|---|---|
| **File** | `data/web_scraped_qa.jsonl` |
| **Format** | JSONL |
| **Records** | 278 question-answer pairs |
| **Origin** | Generated by GPT-4o-mini from content scraped from 5 authoritative sources |
| **Date** | March 2, 2026 |
| **Schema** | `{"question": "...", "answer": "...", "source": "domain.com", "url": "https://..."}` |
| **Sources** | smokefree.gov, CDC, Mayo Clinic, American Cancer Society, American Lung Association |
| **Built by** | `scripts/build_web_dataset.py` |
| **Used by** | `scripts/ragas_evaluation.py` (as `web_rag`) |

This dataset replicates Ibrahim's WebRAG approach but pre-generates the QA pairs from web content rather than fetching live at query time. Each page was scraped, cleaned, and fed to GPT-4o-mini to produce 8 QA pairs per page, then deduplicated.

### 4. Test Set (150 Questions)

| Property | Value |
|---|---|
| **Clean version** | `data/test_set/test_set_150q_clean.xlsx` (also `150_qa_testset.xlsx`) |
| **Reviewed version** | `data/test_set/test_set_150q_lfv_reviewed_oct2025.xlsx` |
| **Format** | Excel (.xlsx), 150 rows, 83+ columns |
| **Records** | 150 questions total; 127 clean + 23 flagged by LFV reviewer |
| **Origin** | Created by Dr. Louis Willis; reviewed by LFV (Oct 30, 2025) |
| **Key columns** | Col 1 = Question, Col 2 = Reference Answer, Col 83 = LFV Comments |
| **Used by** | `scripts/ragas_evaluation.py`, `scripts/latency_comparison.py`, `autoresearch/` |

The test set is the held-out evaluation benchmark. The LFV reviewer flagged 23 questions (with comments in column 83), leaving 127 clean questions used for evaluation. A critical finding was that 47% of these questions had significant overlap with the training datasets, revealing data leakage.

### 5. QuitTxt SMS Message Templates

| Property | Value |
|---|---|
| **File** | `data/quittxt_sms_message_templates.xlsx` (renamed from `Keywords_Settings.xlsx`) |
| **Format** | Excel (.xlsx), 26 rows, 14 columns |
| **Content** | SMS intervention message templates in English and Spanish |
| **Categories** | Crave, BadMood, Stress, Smokers, Alcohol response messages |

This file contains the actual SMS messages sent to participants in the QuitTxt cessation program. It is reference material for understanding the clinical context, not used directly in any evaluation script.

### 6. ChromaDB Vector Database

| Property | Value |
|---|---|
| **Location** | `data/chroma_db/chroma.sqlite3` |
| **Format** | SQLite3 (ChromaDB persistent storage) |
| **Size** | ~9.3 MB |
| **Content** | Pre-built vector embeddings of QA pairs |

A persistent ChromaDB vector store. Note that the evaluation scripts (`ragas_evaluation.py`, `fair_rag_evaluation.py`) build ephemeral in-memory ChromaDB collections each run, so this file may be from an older run or the Streamlit app.

## Evaluation Result Files

### RAGAS Evaluation Results (`results/ragas_evaluation/`)

Checkpoint files (JSONL, one line per answered question):

| File Pattern | Config | Description |
|---|---|---|
| `checkpoint_baseline_100.jsonl` | baseline | GPT-4o-mini with no RAG context |
| `checkpoint_human_rag_100.jsonl` | human_rag | RAG with human-curated dataset |
| `checkpoint_ai_rag_100.jsonl` | ai_rag | RAG with AI-generated dataset |
| `checkpoint_web_rag_100.jsonl` | web_rag | RAG with web-scraped dataset |
| `checkpoint_concise_*.jsonl` | (concise variants) | Same configs with strict concise prompting |

Each checkpoint line: `{"q_idx": 0, "question": "...", "answer": "...", "contexts": [...], "ground_truth": "..."}`

Summary files (JSON + Markdown pairs, timestamped):

| File | Description |
|---|---|
| `ragas_eval_YYYYMMDD_HHMMSS.json` | Full RAGAS metric scores per question |
| `ragas_eval_YYYYMMDD_HHMMSS.md` | Human-readable summary table |
| `ragas_eval_concise_*.json/.md` | Same, but with concise prompting mode |

### Fair Evaluation Results (`results/fair_evaluation_jan2026/`)

Phase 1 evaluation using BLEU/ROUGE metrics on 15 hand-picked test questions.

### Latency Results (`results/latency_comparison/`)

Per-question timing data comparing WebRAG (warm/cold) vs Dataset RAG.

### Autoresearch Results (`autoresearch/results.tsv`)

TSV log of autonomous experiment iterations. Columns: experiment_id, timestamp, hypothesis, target_config, faithfulness_proxy, avg_words, min_words, max_words, temperature, max_tokens, top_k, verdict.
